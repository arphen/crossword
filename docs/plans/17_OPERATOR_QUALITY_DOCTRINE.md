# Operator Quality Doctrine (Q02 field manual)

Status: active. Owner: the operator's chat verdicts. Enforcer: the strict
admission lane. Judge: the NYT census (falsifies universality, never the
strict scope) plus the blind queues (taste).

## Principle

The strict lane holds tighter-than-NYT standards on purpose. The census
measures editors; strict measures what a weak model needs. "Slalom sport"
proves editors clear a higher bar without the rule — it does not prove our
model clears it. A demand stands in strict when operator verdicts require
it, even against census disagreement, and the disagreement is recorded
beside the rule rather than used to kill it.

## Literalism doctrine (operator-stated)

Literal description is licensed only twice: for ambiguous answers the
description fits several fills of (iota/atad/atom as small amount;
Ava/Eve as names), where crossings disambiguate, and for precise
technical facts ("bohr, in physics"). Everyday words clued by bare
literal description ("Light source for a peaceful ambiance" for CANDLE)
are unlicensed: no ambiguity, no technicality, no route.

## Mission queue (subagent-ready work units)

1. **Abbreviation drafting lane.** Prompt variant with abbreviation frames
   (`for short`, `Abbr.`-suffix, enumerations) from Lane G shapes. Measure
   admission plus abbreviation-family rate vs champion, same seeds.
2. **Utterance pipeline, sentences plus judge.** Blanking helper built;
   remaining: ten-sentence generation per word, judge pick, blank. The lane
   produces zero `""` clues today.
3. **Name lane.** Episteme-sourced names plus source-backed senses;
   obscurity flag (AREPO pattern) for the unsourced remainder.
4. **Family quotas.** NYT census mixes replace asserted diversity floors in
   drafting targets.
5. **Delimited drafts.** Pipe-delimited per-entry drafts vs JSON schema on
   malformed rates (second vote: JSON is the failure point).
6. **Episteme weights.** Regional/language wordlist drift; clue-side here,
   fill-side in the sibling checkout.
7. **Multilingual crosswords.** Needs the language-lane inventory first
   (done: Lane H). Polish-weight investigation queued behind it.

## Standing orders for missions

One variable per mission. Counts-only receipts. Answer-bearing text stays
local. Green gates before every commit, never `--no-verify`. A mission
that falsifies its own demand reverts the demand the same day.
